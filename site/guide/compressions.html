The blocks of a container file are compressed one by one, with the compression named in the file's avro.codec. The package reads and writes all six that the Avro specification names, in pure Dart, so a file from Java, Python, Spark or Kafka is readable whatever it was compressed with.

The six compressions

Name ReadWriteNotes
null yes yes No compression; the default of the writers
deflate yes yes Raw DEFLATE, as the specification says, through dart:io
snappy yes yes Snappy, implemented in this package, with the big-endian CRC32 of the uncompressed block after it, checked on reading
bzip2 yes yes Through the package archive
xz yes yes Through archive; written stored, without being compressed
zstandardyes yes Through archive; written with the frame's checksum

Pass the name as compression: to AvroFileWriter or AvroFileStreamWriter; the readers take it from the file and show it as header.compression. Every block of a file uses the same compression, and the records read back the same whichever it is: 

import 'dart:typed_data';

import 'package:avro/avro.dart';

void main() {
  final codec = AvroCodec(writer: Schema.parse('''
  {"type": "record", "name": "Line", "fields": [{"name": "text", "type": "string"}]}
  '''));
  final records = [
    for (var i = 0; i < 1000; i++) {'text': 'line $i of a repetitive log'},
  ];
  final sync = Uint8List(16);

  Uint8List write(String compression) {
    final writer = AvroFileWriter(codec, compression: compression, syncMarker: sync);
    records.forEach(writer.add);
    return writer.close();
  }

  final plain = write('null');
  for (final compression in ['null', 'deflate', 'snappy', 'bzip2', 'xz', 'zstandard']) {
    final file = write(compression);
    final reader = AvroFileReader(file);
    final back = reader.records().toList();
    final smaller = file.length < plain.length ? 'smaller' : 'not smaller';
    print('${reader.header.compression}: ${back.length} records, $smaller than null');
  }

  try {
    AvroFileWriter(codec, compression: 'lz4');
  } on UnsupportedCompressionException catch (e) {
    print(e);
  }
}
null: 1000 records, not smaller than null
deflate: 1000 records, smaller than null
snappy: 1000 records, smaller than null
bzip2: 1000 records, smaller than null
xz: 1000 records, not smaller than null
zstandard: 1000 records, smaller than null
UnsupportedCompressionException: blocks cannot be compressed with "lz4"; only null, deflate, snappy, bzip2, xz and zstandard

Which to choose

  • deflate is the one the specification requires every implementation to read, and a safe choice when the file leaves your system.
  • snappy, bzip2 and zstandard are optional in the specification: choose one when the readers of your files support it.
  • xz is for reading files that others wrote. archive writes xz only as stored data, so a file this package writes with xz is a valid xz file, readable by any Avro implementation that reads xz, but no smaller than one with null.

Checksums

Each snappy block carries the CRC32 of its uncompressed data, as the specification requires; a block whose data does not match throws DecodeException. zstandard blocks are written with the checksum of the zstandard frame, so that a damaged block cannot be read as other records, and the checksums of bzip2, xz and zstandard are verified on reading whenever a block has them. Every block also ends with the file's sync marker, whatever its compression.

Limits stop decompression

A small compressed block can expand to gigabytes. For every compression, the readers stop decompressing as soon as a block passes maxBlockBytes or the file passes maxTotalBytes, and throw LimitExceededException; a bomb is never decompressed in full. snappy declares its length first, so a block that declares too much is refused before anything is allocated. The limits guide shows it.

The decoders of archive have memory caps of their own, such as a zstandard window over 128 MiB. A block over one of those is not over an AvroLimits field, so it throws DecodeException, saying which cap it hit.

Unknown compressions

A compression other than the six throws UnsupportedCompressionException, whose compression is the name: from the writers' constructors for the argument, with nothing written, and from AvroFileReader and AvroFileStreamReader.open for a file whose avro.codec names one, before any block is read. A file without avro.codec is a file of null.
