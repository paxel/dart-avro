dart run avro:generate turns .avsc files into one Dart library: an immutable class for every record and a Dart enum for every enum. A TypedCodec then encodes and decodes those classes with everything an AvroCodec does: schema resolution, single-object encoding and container files.

Run the command

dart run avro:generate schemas/ -o lib/src/types.g.dart
  • Inputs are .avsc files and directories, in the order given. A directory stands for every .avsc file below it, sorted by path. A file named twice is read once.
  • -o, or --output, is the Dart file to write.
  • --prefix <namespace>=<Prefix>, repeatable, puts Prefix before the names of the types of exactly that namespace: --prefix axt=Axt makes axt.DateTime the class AxtDateTime. The prefix must be in UpperCamelCase.

The command writes the whole library, then formats it with dart format where it lies, so it follows the language version of your package. The output imports only package:avro/avro.dart and, when it needs Uint8List, dart:typed_data. It passes the strict analysis with no ignore comments.

Exit codeWhen
0 The library was written, perhaps with warnings
1 A file cannot be read or is not a valid schema, two definitions of a type differ, a name cannot be generated or clashes, or dart format failed
2 A wrong argument: no input, no -o, an unknown option or a malformed --prefix

On a failure the message names the file, and nothing is written. A clash of names says which --prefix would resolve it: 

avro:generate: schemas/axt/DateTime.avsc: the Dart name DateTime of "axt.DateTime" would clash with DateTime of dart:core, dart:typed_data or package:avro; add --prefix axt=Axt

Warnings go to standard error too, and the command still succeeds: a --prefix whose namespace has no record or enum, and a type defined in several files whose documentation or attributes differ (see below).

Commit the generated file and review it like any other source. When a schema changes, run the command again; a test that compares the committed file with a fresh run keeps the two from drifting apart.

A first class

The examples on this page use one schema, memo.avsc, generated into types.g.dart with dart run avro:generate memo.avsc -o types.g.dart: 

{
  "type": "record",
  "name": "Memo",
  "namespace": "com.example",
  "doc": "A short note.",
  "fields": [
    {"name": "text", "type": "string", "doc": "What the memo says."},
    {"name": "written_at", "type": ["null", {"type": "long", "logicalType": "timestamp-millis"}], "default": null},
    {"name": "mood", "type": {"type": "enum", "name": "Mood", "symbols": ["CALM", "IN_A_HURRY"]}, "default": "CALM"},
    {"name": "tags", "type": {"type": "array", "items": "string"}, "default": []},
    {"name": "reply_to", "type": ["null", "Memo"], "default": null}
  ]
}

The class is used like any immutable value. TypedCodec(Memo.avroType) encodes it into exactly the bytes an AvroCodec writes for its generic value, Memo.avroType.toAvro(memo), and decodes them back: 

import 'package:avro/avro.dart';

import 'types.g.dart';

void main() {
  final memo = Memo(
    text: 'Vet, Tuesday 10:00',
    writtenAt: DateTime.utc(2025, 11, 15, 10),
    mood: Mood.inAHurry,
    tags: ['pets'],
  );
  print(memo);

  final codec = TypedCodec(Memo.avroType);
  final bytes = codec.encode(memo);
  print('${bytes.length} bytes');
  print(codec.decode(bytes) == memo);

  // The same bytes as AvroCodec writes for the generic value.
  final generic = Memo.avroType.toAvro(memo);
  print(generic);
  print(AvroCodec(writer: Memo.avroType.schema).decode(bytes));

  final reply = Memo(text: 'OK', mood: Mood.calm, tags: const [], replyTo: memo);
  print(reply.replyTo?.text);
  print(reply.copyWith(text: 'OK, see you').text);
  print(Mood.fromSymbol('IN_A_HURRY') == Mood.inAHurry);
  print(Mood.calm.symbol);
}

What the schema becomes

Schema Dart
record A final class of the record's name
enum A Dart enum; each value has its symbol, and fromSymbol looks one up
boolean, int, long, float, double, stringbool, int, int, double, double, String
bytes, fixed Uint8List; a fixed gets no class
array, map List<T>, Map<String, T>
["null", T], in either order T?
any other union Object?, holding the generic value
a logical type Its Dart value, as in the value mapping: DateTime, AvroDecimal, …
a field of type null No Dart field; its value is always null

Names

A class or enum takes the simple name of its type, in UpperCamelCase, with the prefix of its namespace if one is given. Fields and enum values become lowerCamelCase: written_at is writtenAt, IN_A_HURRY is inAHurry, HTTPCode is httpCode. A name that is a Dart reserved word or a member of the generated code gets a $ at the end: class becomes class$, hashCode becomes hashCode$. The map that toAvro returns keeps the Avro names.

The generator stops when two fields or two symbols give one Dart name, when two types give one class name, and when a class name would hide a type of dart:core, dart:typed_data or package:avro, such as DateTime.

Unions

A union of null and one type is a nullable field. Any other union is an Object? holding the generic value of its branch, as an AvroCodec takes it: where several branches fit, a Branch names one. Decoding gives the plain value, never a Branch. Lists, maps and bytes compare by their elements: 

{
  "type": "record",
  "name": "Reading",
  "fields": [
    {"name": "value", "type": ["int", "long", "string"]},
    {"name": "class", "type": "string"},
    {"name": "raw", "type": "bytes"},
    {"name": "labels", "type": {"type": "map", "values": "string"}}
  ]
}
import 'dart:typed_data';

import 'package:avro/avro.dart';

import 'types.g.dart';

void main() {
  final reading = Reading(
    // 5 fits int and long: name the branch.
    value: const Branch('long', 5),
    class$: 'B',
    raw: Uint8List.fromList([1, 2]),
    labels: {'unit': 'kg'},
  );
  final codec = TypedCodec(Reading.avroType);
  final back = codec.decode(codec.encode(reading));
  print(back);
  print(back.value.runtimeType);

  // Lists, maps and bytes compare by their elements.
  print(back == reading.copyWith(value: 5));
  print(back.hashCode == reading.copyWith(value: 5).hashCode);
}

Inline and repeated types

A record or enum defined inside another schema gets a type of its own, like Mood above, and a record may refer to itself, like replyTo. A type defined in several files, which happens when each file defines the types it uses, becomes one Dart type if the definitions have the same canonical form. The first definition in input order is used; if another one differs in its documentation or attributes, the command warns and goes on: 

avro:generate: warning: "axt.DateTime" in types/b.avsc differs from types/a.avsc in its docs or attributes; the definition in types/a.avsc is used

Definitions with different fields stop the generator.

Schema text

Each class carries its schema's JSON text, parsed once on first use as Memo.avroType.schema. For a type that is the whole of an .avsc file, it is the file's text exactly, documentation and attributes included. A type defined inside another carries a JSON text of its own definition that parses on its own.

The generated members

An excerpt of what the command wrote for memo.avsc:

/// A short note.
final class Memo {
  const Memo({
    required this.text,
    this.writtenAt,
    required this.mood,
    required this.tags,
    this.replyTo,
  });

  /// What the memo says.
  final String text;

  final DateTime? writtenAt;

  final Mood mood;

  final List<String> tags;

  final Memo? replyTo;

  /// The schema of [Memo] and the conversion from and to the generic values of AvroCodec.
  static final AvroType<Memo> avroType = AvroType<Memo>(
    schemaJson: '''{
  "type": "record",
  …
}
''',
    toAvro: (value) => <String, Object?>{
      'text': value.text,
      'written_at': value.writtenAt,
      'mood': value.mood.symbol,
      'tags': value.tags,
      'reply_to': switch (value.replyTo) {
        final v0? => Memo.avroType.toAvro(v0),
        null => null,
      },
    },
    fromAvro: (value) {
      final m = value as Map<String, Object?>;
      return Memo(
        text: m['text'] as String,
        writtenAt: m['written_at'] as DateTime?,
        mood: Mood.fromSymbol(m['mood'] as String),
        tags: [for (final x0 in m['tags'] as List<Object?>) x0 as String],
        replyTo: switch (m['reply_to']) {
          final v0? => Memo.avroType.fromAvro(v0),
          null => null,
        },
      );
    },
  );

  /// A copy with the given fields replaced. A null argument keeps the field,
  /// so `copyWith` cannot set a nullable field to null.
  Memo copyWith({
    String? text,
    DateTime? writtenAt,
    Mood? mood,
    List<String>? tags,
    Memo? replyTo,
  }) => Memo(
    text: text ?? this.text,
    writtenAt: writtenAt ?? this.writtenAt,
    mood: mood ?? this.mood,
    tags: tags ?? this.tags,
    replyTo: replyTo ?? this.replyTo,
  );

  // … ==, hashCode and toString
}

enum Mood {
  calm('CALM'),
  inAHurry('IN_A_HURRY');

  const Mood(this.symbol);

  /// The Avro symbol of the value.
  final String symbol;

  /// The value of the Avro symbol [symbol]. Throws [ArgumentError] for any other string.
  static Mood fromSymbol(String symbol) => switch (symbol) {
    'CALM' => calm,
    'IN_A_HURRY' => inAHurry,
    _ => throw ArgumentError.value(symbol, 'symbol', 'not a symbol of Mood'),
  };
}
  • The constructor is const, with named parameters. Non-nullable fields are required; nullable ones default to null. Avro defaults are not constructor defaults: they are for schema resolution only.
  • == and hashCode compare every field; lists, maps, bytes and Object? fields compare by their elements.
  • toString shows the Dart field names and their values.
  • copyWith replaces the fields you pass. A null argument keeps the field, so copyWith cannot set a nullable field to null; build a new value for that.
  • avroType is the AvroType of the class: the schema text, and toAvro and fromAvro between the class and the generic value of AvroCodec.

TypedCodec

TypedCodec(Memo.avroType) encodes and decodes with the class's schema. TypedCodec(Memo.avroType, writer: older) reads data written with another schema, by schema resolution, as AvroCodec(writer:, reader:) does; a schema that does not resolve throws ResolutionException there. Encoding always writes the class's own schema. encodeSingleObject and decodeSingleObject are the single-object encoding, with the fingerprint of the class's schema. 

import 'package:avro/avro.dart';

import 'types.g.dart';

void main() {
  // An older version of the schema, without the mood and the reply.
  final v1 = Schema.parse('''
  {"type": "record", "name": "Memo", "namespace": "com.example", "fields": [
    {"name": "text", "type": "string"},
    {"name": "written_at", "type": ["null", {"type": "long", "logicalType": "timestamp-millis"}]},
    {"name": "tags", "type": {"type": "array", "items": "string"}}
  ]}
  ''');
  final old = AvroCodec(writer: v1).encode({
    'text': 'Buy milk',
    'written_at': null,
    'tags': ['home'],
  });

  final codec = TypedCodec(Memo.avroType, writer: v1);
  print(codec.decode(old));

  // Encoding always writes the type's own schema, never the writer's.
  final bytes = codec.encode(const Memo(text: 'New', mood: Mood.calm, tags: []));
  print(TypedCodec(Memo.avroType).decode(bytes).text);

  // Single-object encoding carries the fingerprint of the type's schema.
  final message = codec.encodeSingleObject(const Memo(text: 'Hi', mood: Mood.calm, tags: []));
  print(SingleObjectHeader.parse(message).fingerprint == Memo.avroType.schema.crc64);
  print(TypedCodec(Memo.avroType).decodeSingleObject(message).text);
}

Container files

codec.avro is the underlying AvroCodec. Give it to AvroFileWriter and AvroFileReader.records, and convert the records with toAvro and fromAvro: 

import 'package:avro/avro.dart';

import 'types.g.dart';

void main() {
  final codec = TypedCodec(Memo.avroType);

  final writer = AvroFileWriter(codec.avro);
  for (final text in ['Vet', 'Milk', 'Call Anna']) {
    writer.add(Memo.avroType.toAvro(Memo(text: text, mood: Mood.calm, tags: const [])));
  }
  final file = writer.close();

  final reader = AvroFileReader(file);
  final memos = reader.records(codec.avro).map(Memo.avroType.fromAvro).toList();
  print(memos.map((m) => m.text).toList());
  print(reader.header.schemaJson == Memo.avroType.schemaJson);
}
[Vet, Milk, Call Anna]
true

A file of an older schema reads the same way with TypedCodec(Memo.avroType, writer: fileSchema).avro, where fileSchema is Schema.parse(reader.header.schemaJson).
