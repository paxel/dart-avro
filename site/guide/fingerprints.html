Two schemas can say the same thing in different words: other spacing, other key order, a documentation string more. The canonical form strips a schema down to what decides its encoding, and a fingerprint is a hash of it, short enough to send with every message.

The canonical form

schema.canonicalForm is the Parsing Canonical Form of the Avro specification, as a String. It is computed once per schema and then kept. The form:

  • writes every name as a full name and drops namespace;
  • keeps only name, type, fields, symbols, items, values and size, in that order;
  • writes a primitive as its name alone: {"type": "int"} becomes "int";
  • writes a named type in full where it first appears, and as its full name after that;
  • has no whitespace outside strings.

So it leaves out doc, aliases, field defaults, order, the enum default, every prop, and logical types with their attributes such as precision and scale. A long and a timestamp-millis on a long have the same canonical form. 

import 'package:avro/avro.dart';

void main() {
  final a = Schema.parse('''
  {"type": "record", "name": "Event", "namespace": "com.example",
   "doc": "Something that happened.", "aliases": ["Happening"],
   "fields": [
     {"name": "at", "type": {"type": "long", "logicalType": "timestamp-millis"},
      "doc": "When.", "default": 0},
     {"name": "kind", "type": {"type": "enum", "name": "Kind",
                               "symbols": ["START", "STOP"], "default": "START"}},
     {"name": "previous", "type": ["null", "Kind"], "default": null, "order": "ignore"}
   ]}
  ''');
  final b = Schema.parse('''
  {"fields": [{"type": "long", "name": "at"},
              {"type": {"symbols": ["START", "STOP"], "type": "enum", "name": "Kind"}, "name": "kind"},
              {"type": ["null", "com.example.Kind"], "name": "previous"}],
   "type": "record", "name": "com.example.Event"}
  ''');

  print(a.canonicalForm);
  print(a.canonicalForm == b.canonicalForm);
}

The fingerprints

A fingerprint is a hash of the UTF-8 bytes of the canonical form:

Getter Hash Dart type
crc64 CRC-64-AVRO (Rabin) int, the 64-bit pattern
md5 MD5 Uint8List of 16 bytes
sha256SHA-256 Uint8List of 32 bytes

The getters come from the extension SchemaFingerprints, which package:avro/avro.dart exports with everything else.

CRC-64-AVRO as an int

The CRC-64-AVRO fingerprint is the one Avro itself uses, in single-object encoding. The package gives it as an int that holds the 64 bits as they are, as Java's long does. When the highest bit is set, the int is negative. As an int, it is a map key and compares with == without any wrapping.

  • crc64ToBytes(fingerprint) gives the 8 little-endian bytes Avro writes.
  • crc64FromBytes(bytes) reads them back; anything but 8 bytes throws ArgumentError.
  • crc64Avro(bytes) computes the CRC-64-AVRO of any bytes, not only of a canonical form.
import 'dart:convert';

import 'package:avro/avro.dart';

void main() {
  final schema = Schema.parse('"string"');

  final crc = schema.crc64;
  print(crc);
  print(BigInt.from(crc).toUnsigned(64).toRadixString(16)); // as an unsigned hex number

  final bytes = crc64ToBytes(crc);
  print(bytes);
  print(crc64FromBytes(bytes) == crc);
  print(crc64Avro(utf8.encode(schema.canonicalForm)) == crc);

  print(schema.md5.length);
  print(schema.sha256.length);
}

To print a fingerprint as an unsigned number, go through BigInt as above; the int itself prints with its sign.

Which fingerprint to use

The specification describes all three. CRC-64-AVRO is short and is what single-object encoding sends, but it is not a cryptographic hash: anyone can make a schema with a given CRC. Use it to find a schema among those you know, never to prove that a schema is one you trust. Where a fingerprint must resist that, compare sha256, or the canonical forms themselves.

The canonical forms and CRC-64-AVRO fingerprints of the package are checked against the Apache Avro test data; see Spec conformance.
