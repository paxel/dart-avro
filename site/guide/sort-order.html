The Avro specification gives every schema but a map an order, the same in every language, so that data sorted by Java sorts the same in Dart. The codec compares two values by it, or two encodings without decoding them.

Comparing values and encodings

  • codec.compare(a, b) compares two values of the writer schema, as encode takes them, and returns -1, 0 or 1. It suits List.sort as it is.
  • codec.compareBytes(a, b) compares two encodings of the writer schema, and gives the same result as compare on the values they hold. It reads both side by side only as far as the first difference, and decodes nothing into Dart values.
  • TypedCodec.compare(a, b) compares two values of a generated class, as compare compares their generic values.

A record compares field by field, in the order of its fields, and each field's order says how: ascending, the default; descending, which turns the field's result around; or ignore, whose values are not looked at, so two records that differ only there are equal. 

import 'package:avro/avro.dart';

void main() {
  final codec = AvroCodec(writer: Schema.parse('''
  {"type": "record", "name": "Score", "fields": [
    {"name": "player", "type": "string"},
    {"name": "points", "type": "int", "order": "descending"},
    {"name": "note", "type": "string", "order": "ignore"}
  ]}
  '''));
  final scores = [
    {'player': 'bob', 'points': 7, 'note': 'late'},
    {'player': 'ada', 'points': 3, 'note': ''},
    {'player': 'ada', 'points': 9, 'note': 'best'},
  ];

  scores.sort(codec.compare);
  for (final s in scores) {
    print(s);
  }

  // The note is ignored: these two are equal.
  print(codec.compare(
    {'player': 'ada', 'points': 9, 'note': 'best'},
    {'player': 'ada', 'points': 9, 'note': 'other'},
  ));

  // The same order on the encodings, without decoding them.
  final a = codec.encode(scores[0]);
  final b = codec.encode(scores[1]);
  print(codec.compareBytes(a, b));
  print(codec.compareBytes(b, a));
}

The values are those of the writer schema: what decode returns for another reader schema is not, and is compared with a codec of that schema. A value that does not fit the schema throws EncodeException from compare, as encode would; bytes that are not a valid encoding throw DecodeException from compareBytes, as far as it reads them. Bytes after the first difference, and after the datums, are not checked.

The rules

Schema Order
null All equal
boolean false before true
int, long, doubleBy value; -0.0 before 0.0, and NaN after every other number and equal to itself, as in Java
float As double, but by the 32-bit value it encodes to: two doubles that round to the same float are equal
bytes, fixedBy their unsigned bytes; a shorter prefix first
string By its UTF-8 bytes, unsigned: Z before a, é after z
enum By the index of the symbol in the schema, not by its name
array Element by element, then a shorter array first
map None: throws ArgumentError
record Field by field in the field's order: ascending, descending or ignore
union By the index of the branch first, then by the value in that branch
logical type As the value of the underlying type it encodes to

The last rule is the specification's, and it does not always follow the number or the time. A decimal compares by the bytes of its two's complement, so a negative decimal comes after a positive one. A duration compares by its 12 bytes, months, days and milliseconds each little-endian, so 256 ms comes before 1 ms. The timestamps, dates and times are int and long values and compare in time order. 

import 'dart:typed_data';

import 'package:avro/avro.dart';

void main() {
  int compare(String schema, Object? a, Object? b) =>
      AvroCodec(writer: Schema.parse(schema)).compare(a, b);

  // A union: by the index of the branch first, then by value.
  print(compare('["null", "string"]', null, 'a'));
  print(compare('["string", "null"]', null, 'a'));

  // Strings and bytes: as unsigned bytes, so 'Z' before 'a' and 'é' after 'z'.
  print(compare('"string"', 'Z', 'a'));
  print(compare('"string"', 'é', 'z'));
  print(compare('"bytes"', Uint8List.fromList([1, 2]), Uint8List.fromList([1, 2, 0])));

  // An enum: by the index of its symbol, not by its name.
  print(compare('{"type": "enum", "name": "Size", "symbols": ["S", "M", "L"]}', 'L', 'M'));

  // A float: as the 32-bit value it encodes to.
  print(compare('"float"', 0.1, 0.10000000001));
  print(compare('"double"', 0.1, 0.10000000001));

  // NaN: after every other number and equal to itself, as in Java.
  print(compare('"double"', double.nan, double.infinity));
  print(compare('"double"', double.nan, double.nan));

  // A decimal: by the bytes of its two's complement, so a negative one after a positive one.
  const decimal = '{"type": "bytes", "logicalType": "decimal", "precision": 5, "scale": 2}';
  print(compare(decimal, AvroDecimal(BigInt.from(-150), 2), AvroDecimal(BigInt.from(150), 2)));

  // A duration: by its 12 bytes, months, days and milliseconds little-endian.
  const duration = '{"type": "fixed", "name": "D", "size": 12, "logicalType": "duration"}';
  print(compare(duration, AvroDuration(0, 0, 256), AvroDuration(0, 0, 1)));

  // A map: no order.
  try {
    compare('{"type": "map", "values": "int"}', {'a': 1}, {'a': 1});
  } on ArgumentError catch (e) {
    print(e.message);
  }
}

Generated classes

TypedCodec.compare takes two values of a generated class and compares them by the sort order of its schema. With this score.avsc: 

{
  "type": "record",
  "name": "Score",
  "namespace": "com.example",
  "fields": [
    {"name": "player", "type": "string"},
    {"name": "points", "type": "int", "order": "descending"},
    {"name": "note", "type": "string", "order": "ignore"}
  ]
}
import 'package:avro/avro.dart';

import 'types.g.dart';

void main() {
  final codec = TypedCodec(Score.avroType);
  final scores = [
    Score(player: 'bob', points: 7, note: 'late'),
    Score(player: 'ada', points: 3, note: ''),
    Score(player: 'ada', points: 9, note: 'best'),
  ]..sort(codec.compare);
  for (final s in scores) {
    print(s);
  }
}
