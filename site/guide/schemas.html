Schema.parse turns the JSON text of a schema into an immutable tree. The tree keeps everything the text says: names, documentation, aliases, defaults and the attributes the Avro specification does not define.

Parse a schema

Schema.parse(jsonText, limits:) reads one schema. A schema is a JSON string such as "int", an object such as {"type": "record", …}, or an array, which is a union. Named types may refer to themselves and to each other by name, so a linked list is one schema. 

import 'package:avro/avro.dart';

void main() {
  final schema = Schema.parse('''
  {"type": "record", "name": "Node", "namespace": "com.example",
   "fields": [
     {"name": "value", "type": "long"},
     {"name": "next", "type": ["null", "Node"], "default": null}
   ]}
  ''');

  print(schema.type);
  print(schema is RecordSchema);

  final record = schema as RecordSchema;
  final next = record.fields[1].schema as UnionSchema;
  print(identical(next.branches[1], record)); // the reference is the record itself
}
record
true
true

The text must fit the schema limits: 1 MiB and a nesting depth of 64 by default. Over a limit, parse throws LimitExceededException; see Untrusted input and limits.

The tree

Schema is a sealed class, so a switch over it covers every kind of schema and the analyzer tells you when one is missing.

Class Avro type Its own members
PrimitiveSchemanull, boolean, int, long, float, double, bytes, string—
RecordSchema record, or error fields, a list of Field
EnumSchema enum symbols, defaultSymbol
FixedSchema fixed size
ArraySchema array items
MapSchema map values
UnionSchema a union branches

RecordSchema, EnumSchema and FixedSchema are the named types. They share the sealed base NamedSchema, with name, namespace, fullName, aliases and doc. Every schema has type, logicalType, props, json (the decoded JSON value) and jsonText. There are no builders: a schema is always parsed from JSON. 

import 'package:avro/avro.dart';

String describe(Schema s) => switch (s) {
  PrimitiveSchema(:final type) => type,
  RecordSchema(:final fullName, :final fields) =>
    'record $fullName with ${fields.length} fields',
  EnumSchema(:final symbols) => 'enum of ${symbols.join(', ')}',
  FixedSchema(:final size) => 'fixed of $size bytes',
  ArraySchema(:final items) => 'array of ${describe(items)}',
  MapSchema(:final values) => 'map of ${describe(values)}',
  UnionSchema(:final branches) => 'one of ${branches.map(describe).join(', ')}',
};

void main() {
  final schema = Schema.parse('''
  {"type": "record", "name": "Reading", "fields": [
    {"name": "sensor", "type": {"type": "fixed", "name": "Id", "size": 4}},
    {"name": "unit", "type": {"type": "enum", "name": "Unit", "symbols": ["C", "F"]}},
    {"name": "values", "type": {"type": "array", "items": "double"}},
    {"name": "labels", "type": {"type": "map", "values": "string"}},
    {"name": "note", "type": ["null", "string"]}
  ]}
  ''') as RecordSchema;

  print(describe(schema));
  for (final field in schema.fields) {
    print('${field.name}: ${describe(field.schema)}');
  }
}
record Reading with 5 fields
sensor: fixed of 4 bytes
unit: enum of C, F
values: array of double
labels: map of string
note: one of null, string

Names and namespaces

A named type has a name and a namespace; fullName joins them with a dot. The rules are the specification's:

  • A name with a dot, such as "com.example.User", is a full name; its namespace is the part before the last dot, and a namespace attribute beside it is ignored.
  • Otherwise the namespace attribute applies, and without one the namespace of the enclosing named type.
  • The empty namespace, "", is the null namespace: namespace is null and the full name is the name alone.
  • A reference by name inside a namespace is looked up as a full name in that namespace first, then as given.
import 'package:avro/avro.dart';

void main() {
  final schema = Schema.parse('''
  {"type": "record", "name": "Order", "namespace": "com.shop",
   "fields": [
     {"name": "state", "type": {"type": "enum", "name": "State", "symbols": ["NEW", "PAID"]}},
     {"name": "id", "type": {"type": "fixed", "name": "org.ids.Id", "size": 8}},
     {"name": "raw", "type": {"type": "fixed", "name": "Raw", "namespace": "", "size": 2}},
     {"name": "previous", "type": ["null", "State"]}
   ]}
  ''') as RecordSchema;

  for (final field in schema.fields) {
    final type = switch (field.schema) {
      final NamedSchema named => named,
      UnionSchema(:final branches) => branches[1] as NamedSchema,
      _ => throw StateError('not named'),
    };
    print('${field.name}: ${type.fullName} (namespace ${type.namespace})');
  }
}
state: com.shop.State (namespace com.shop)
id: org.ids.Id (namespace org.ids)
raw: Raw (namespace null)
previous: com.shop.State (namespace com.shop)

Doc, aliases and props

doc is the documentation of a named type or a field, or null. The aliases of a named type are full names: an alias without a dot takes the type's namespace. The aliases of a field are kept as given. Schema resolution uses both.

Props are the attributes the specification does not define, such as "axt.title", as decoded JSON values. Types and fields each have their own props; a union has none, because it is a JSON array. The attributes of a logical type, such as precision and scale of a decimal, are props as well. logicalType returns the attribute as written, even for a logical type the package does not know; such a schema is read as its underlying type. 

import 'package:avro/avro.dart';

void main() {
  final memo = Schema.parse('''
  {"type": "record", "name": "Memo", "namespace": "com.example",
   "doc": "A short note.", "aliases": ["Note", "legacy.Memo"], "axt.title": "Memo",
   "fields": [
     {"name": "text", "type": "string", "doc": "The note itself.",
      "aliases": ["body"], "axt.maxLength": 280},
     {"name": "price", "type": {"type": "bytes", "logicalType": "decimal",
                                "precision": 9, "scale": 2}},
     {"name": "colour", "type": {"type": "string", "logicalType": "x-colour"}}
   ]}
  ''') as RecordSchema;

  print(memo.doc);
  print(memo.aliases);
  print(memo.props);

  final text = memo.fields[0];
  print('${text.doc} ${text.aliases} ${text.props}');

  final price = memo.fields[1].schema;
  print('${price.logicalType} ${price.props}');
  print(memo.fields[2].schema.logicalType);
}
A short note.
[com.example.Note, legacy.Memo]
{axt.title: Memo}
The note itself. [body] {axt.maxLength: 280}
decimal {precision: 9, scale: 2}
x-colour

A field also has order: ascending (the default), descending or ignore. The package keeps it but does not sort by it.

Defaults as Dart values

A field's default is parsed when the schema is, and must fit the field's schema, or parse throws SchemaParseException. hasDefault says whether the field has one; defaultValue holds it as the Dart value a decoder would return, so a default of null and no default differ only in hasDefault.

  • A bytes or fixed default is a JSON string of the characters U+0000 to U+00FF, one per byte, as the specification says; it becomes a Uint8List.
  • A default of a logical type is written as its underlying type and becomes the logical type's Dart value: 0 for a date is AvroDate(1970, 1, 1).
  • A record default may leave out fields that have defaults of their own.
  • A union default is the value of the first branch it fits.
import 'package:avro/avro.dart';

void main() {
  final schema = Schema.parse(r'''
  {"type": "record", "name": "Settings", "fields": [
    {"name": "magic", "type": {"type": "fixed", "name": "Magic", "size": 2},
     "default": "Ã\u0001"},
    {"name": "since", "type": {"type": "int", "logicalType": "date"}, "default": 20413},
    {"name": "tags", "type": {"type": "array", "items": "string"}, "default": ["new"]},
    {"name": "nickname", "type": ["null", "string"], "default": null},
    {"name": "email", "type": ["null", "string"]}
  ]}
  ''') as RecordSchema;

  for (final f in schema.fields) {
    print('${f.name}: ${f.hasDefault} ${f.defaultValue} '
        '(${f.defaultValue.runtimeType})');
  }
}
magic: true [195, 1] (Uint8List)
since: true 2025-11-21 (AvroDate)
tags: true [new] (List<Object?>)
nickname: true null (Null)
email: false null (Null)

Defaults serve schema resolution only: encode still needs every field. See Values and unions.

The JSON text

jsonText of the parsed schema is the text exactly as you passed it, spaces included. A nested schema has no text of its own; its jsonText is its JSON value encoded again. For a reference to a named type, that is the definition's JSON. The canonical form is a different thing: the normalised text that fingerprints are made of. 

import 'package:avro/avro.dart';

void main() {
  final schema = Schema.parse('''{ "type": "array",  "items": {"type": "fixed", "name": "Id", "size": 4} }''');

  print(schema.jsonText);
  print((schema as ArraySchema).items.jsonText);
}
{ "type": "array",  "items": {"type": "fixed", "name": "Id", "size": 4} }
{"type":"fixed","name":"Id","size":4}

AvroFileWriter writes the root text into a container file's header, unless you pass another schemaJson.

When parsing fails

Text that is not JSON, or not a valid Avro schema, throws SchemaParseException. Its message says what is wrong, and its path says where: the full name of the record and the index of the field, such as Memo.fields[1].type, or $ and an index for the root. path is null when the text is not JSON. 

import 'package:avro/avro.dart';

void main() {
  for (final text in [
    '{"type": "record", "name": "Memo", "fields": [{"name": "text", "type": "strng"}]}',
    '{"type": "record", "name": "Memo", "fields": [{"name": "n", "type": "int", "default": "1"}]}',
    '{"type": "enum", "name": "Colour", "symbols": ["RED", "RED"]}',
    '["null", "string", "null"]',
    '{"type": "record", "name": "Memo"',
  ]) {
    try {
      Schema.parse(text);
    } on SchemaParseException catch (e) {
      print('${e.path}: ${e.message}');
    }
  }
}
Memo.fields[0].type: unknown type "strng"
Memo.fields[0].default: the default "1" does not fit int
$: the symbol "RED" is twice
$[2]: the union holds null twice
null: not JSON: Unexpected end of input

Among the checks: names and symbols must match [A-Za-z_][A-Za-z0-9_]*, a named type is defined once, a union holds no union and no two branches of the same type or full name, an enum default is one of its symbols, and a fixed has a non-negative size.
