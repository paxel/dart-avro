An AvroCodec works with plain Dart values: maps, lists, strings, numbers and a few classes of the package for logical types. This page shows what encode accepts, how it picks the branch of a union, and what decode gives back.

The plain values

Avro type encode accepts decode returns
null null null
booleanbool bool
int int within 32 bits int
long int int
float num double
double num double
bytes Uint8List Uint8List
string String, without unpaired surrogates String
record Map<String, Object?> of exactly its fieldsMap<String, Object?> in field order
enum String, one of the symbols String
array List<Object?> List<Object?>
map Map<String, Object?> Map<String, Object?>
fixed Uint8List of exactly the size Uint8List
union the value of a branch, or a Branch the value of the branch

The logical types have their own values, such as DateTime for timestamp-millis and AvroDecimal for decimal; the value mapping lists them all. A List<int> is not bytes: use Uint8List, from dart:typed_data. 

import 'dart:typed_data';

import 'package:avro/avro.dart';

void main() {
  final codec = AvroCodec(writer: Schema.parse('''
  {"type": "record", "name": "Sample", "fields": [
    {"name": "ok", "type": "boolean"},
    {"name": "count", "type": "int"},
    {"name": "ratio", "type": "float"},
    {"name": "raw", "type": "bytes"},
    {"name": "unit", "type": {"type": "enum", "name": "Unit", "symbols": ["C", "F"]}},
    {"name": "points", "type": {"type": "array", "items": "long"}},
    {"name": "labels", "type": {"type": "map", "values": "string"}}
  ]}
  '''));

  final bytes = codec.encode({
    'ok': true,
    'count': 3,
    'ratio': 1, // a num is fine for float and double
    'raw': Uint8List.fromList([0xca, 0xfe]),
    'unit': 'C',
    'points': [1, 2, 3],
    'labels': {'site': 'roof'},
  });
  print(codec.decode(bytes));
}
{ok: true, count: 3, ratio: 1.0, raw: [202, 254], unit: C, points: [1, 2, 3], labels: {site: roof}}

Records are strict

The map of a record must hold every field of the record and nothing else. A missing field throws EncodeException, even when the field has a default: defaults serve schema resolution only, as in the specification. A key that names no field throws as well, so a typo does not vanish silently.

The exception's path names the place in the value: $ is the value itself, $.points[1] the second item of the field points, $.labels.site the entry site of a map. 

import 'package:avro/avro.dart';

void main() {
  final codec = AvroCodec(writer: Schema.parse('''
  {"type": "record", "name": "User", "fields": [
    {"name": "name", "type": "string"},
    {"name": "age", "type": "int", "default": 0},
    {"name": "scores", "type": {"type": "array", "items": "int"}}
  ]}
  '''));

  for (final value in [
    {'name': 'Ada', 'scores': <Object?>[]},
    {'name': 'Ada', 'age': 36, 'scores': <Object?>[], 'email': 'ada@example.com'},
    {'name': 'Ada', 'age': 36, 'scores': [1, 'two']},
    {'name': 'Ada', 'age': 1 << 40, 'scores': <Object?>[]},
  ]) {
    try {
      codec.encode(value);
    } on EncodeException catch (e) {
      print(e);
    }
  }
}
EncodeException at $: the field "age" is missing
EncodeException at $: "email" is not a field of User
EncodeException at $.scores[1]: expected int for int, got String
EncodeException at $.age: 1099511627776 does not fit 32 bits

How a union branch is chosen

A value of a union is encoded as the index of its branch and the value. When you pass a plain value, the codec checks it against every branch:

Branch Fits
null null
boolean a bool
int an int within 32 bits
long any int
float, double a double, not an int
bytes a Uint8List
string a String
fixed a Uint8List of its size
enum a String that is one of its symbols
array a List that is not a Uint8List
map a Map<String, Object?>
record a Map<String, Object?> with exactly its field names as keys
a logical type a value of the logical type, such as a DateTime; a uuid a String in UUID form

The check looks only at the outside of the value. If exactly one branch fits, the codec takes it, and the value must then encode with that branch. If none fits, encode throws and lists the branches. If more than one fits, encode throws and names the candidates; the codec never guesses. 

import 'package:avro/avro.dart';

void main() {
  final codec = AvroCodec(writer: Schema.parse('''
  ["null", "string", "double",
   {"type": "record", "name": "Point", "fields": [{"name": "x", "type": "int"}]}]
  '''));

  for (final value in [null, 'text', 2.5, {'x': 1}, 7, true]) {
    try {
      final bytes = codec.encode(value);
      print('$value: branch ${bytes.first ~/ 2}');
    } on EncodeException catch (e) {
      print('$value: ${e.message}');
    }
  }
}
null: branch 0
text: branch 1
2.5: branch 2
{x: 1}: branch 3
7: no branch of the union fits int; it has null, string, double, Point
true: no branch of the union fits bool; it has null, string, double, Point

The first byte of a union's encoding is the branch index as a zig-zag varint, which is why the example halves it. Note the 7: an int does not fit a double branch, although a plain double schema accepts one. Pass 7.0 instead.

Naming the branch with Branch

Some unions have branches that the same value fits. The common ones:

  • ["int", "long"]: any int within 32 bits.
  • ["float", "double"]: every double.
  • An enum and string: a symbol.
  • A fixed and bytes: a Uint8List of the fixed's size.
  • A record and a map, or two records with the same field names.

For those, wrap the value: Branch(name, value). The name is the full name of a named type, such as com.example.Point, or the type name of any other: long, array, map. A branch with a logical type is named by its underlying type, so a timestamp-millis branch is long. A Branch is checked against its branch only. A name the union does not have, or a Branch where the schema is not a union, throws EncodeException. 

import 'package:avro/avro.dart';

void main() {
  final codec = AvroCodec(writer: Schema.parse('''
  [{"type": "enum", "name": "com.example.Colour", "symbols": ["RED", "GREEN"]}, "string"]
  '''));

  print(codec.encode('blue')); // only string fits
  try {
    codec.encode('RED');
  } on EncodeException catch (e) {
    print(e.message);
  }
  print(codec.encode(const Branch('com.example.Colour', 'RED')));
  print(codec.encode(const Branch('string', 'RED')));
  print(codec.decode(codec.encode(const Branch('string', 'RED'))));
}
[2, 8, 98, 108, 117, 101]
more than one branch fits; wrap the value in a Branch of one of com.example.Colour, string
[0, 0]
[2, 6, 82, 69, 68]
RED

What decode returns

decode returns plain values, and a Branch only for a codec made with decodeBranches: true. Records come back as maps with one entry per field of the reader schema, in its field order; lists and maps are new, growable objects that you may change. Without decodeBranches, two branches that decode to the same kind of value, such as two records with the same fields, cannot be told apart afterwards; see Decoding into Branch below.

decode reads exactly one datum: bytes left over after it throw DecodeException, and so does any byte that is not a valid encoding, with the offset of the failing byte. For several datums in a row, use a container file. 

import 'dart:typed_data';

import 'package:avro/avro.dart';

void main() {
  final codec = AvroCodec(writer: Schema.parse('["null", "long"]'));

  print(codec.decode(Uint8List.fromList([2, 84]))); // branch 1, the long 42

  for (final bytes in [
    [2, 84, 0], // one byte too many
    [4, 0], // there is no branch 2
    [2], // the long is missing
  ]) {
    try {
      codec.decode(Uint8List.fromList(bytes));
    } on DecodeException catch (e) {
      print('${e.offset}: ${e.message}');
    }
  }
}
42
2: 1 bytes left over after the datum
0: the union has no branch 2
1: needs 1 bytes, but only 0 are left

Decoding into Branch

AvroCodec(writer:, decodeBranches: true) decodes the value of every union with two or more non-null branches as a Branch of the branch it was in, so you can tell two records with the same fields apart, and a decoded value encodes back to the same bytes, branch for branch. null, and the value of a union of null and one other type, stay plain. The option is off by default.

It applies wherever the codec decodes: decode, decodeSingleObject, decodeJson, the records of a container file read with the codec, and the reader defaults that schema resolution fills in. With a reader schema, the Branch names the reader's branch. TypedCodec always decodes this way, which is how generated code knows the branch of a union. 

import 'package:avro/avro.dart';

void main() {
  final schema = Schema.parse('''
  {"type": "record", "name": "Shape", "namespace": "com.example", "fields": [
    {"name": "kind", "type": [
      {"type": "record", "name": "Square", "fields": [{"name": "side", "type": "double"}]},
      {"type": "record", "name": "Circle", "fields": [{"name": "side", "type": "double"}]}
    ]},
    {"name": "label", "type": ["null", "string"]},
    {"name": "size", "type": ["null", "int", "long"]}
  ]}
  ''');
  final value = {
    'kind': const Branch('com.example.Circle', {'side': 2.0}),
    'label': 'disc',
    'size': const Branch('long', 7),
  };
  final bytes = AvroCodec(writer: schema).encode(value);

  print(AvroCodec(writer: schema).decode(bytes));
  final branches = AvroCodec(writer: schema, decodeBranches: true);
  final back = branches.decode(bytes);
  print(back);

  // The value encodes back to the same bytes, branch for branch.
  print(branches.encode(back).toString() == bytes.toString());
  print(branches.decode(AvroCodec(writer: schema).encode({...value, 'size': null})));
}
{kind: {side: 2.0}, label: disc, size: 7}
{kind: Branch(com.example.Circle, {side: 2.0}), label: disc, size: Branch(long, 7)}
true
{kind: Branch(com.example.Circle, {side: 2.0}), label: disc, size: null}

Branch compares its name and its value with ==, so two Branches of equal maps are not equal unless the maps are the same object.
