One task per page, each with programs you can run as they are. Read them in any order; each page links to the others where they meet.

  • Chapter 1

    Schemas and attributes

    Parse a schema, walk its sealed tree, and read names, doc, aliases, props and defaults.

  • Chapter 2

    Values and unions

    The plain Dart values, strict records, how a union branch is inferred, Branch and decodeBranches.

  • Chapter 3

    Schema resolution

    Read old data as a new schema: promotions, aliases, defaults, enums and unions.

  • Chapter 4

    Single-object encoding

    One value with the fingerprint of its schema, and choosing the codec by fingerprint.

  • Chapter 5

    JSON encoding

    encodeJson and decodeJson: union branches, bytes, NaN, resolution and strict input.

  • Chapter 6

    Container files

    Write files with metadata and compression; read the header first, then the records.

  • Chapter 7

    Compressions

    null, deflate, snappy, bzip2, xz and zstandard, their checksums and their limits.

  • Chapter 8

    Streamed container files

    Read a file from a Stream and write one to a StreamSink, one block in memory at a time.

  • Chapter 9

    Fingerprints and canonical form

    The Parsing Canonical Form, CRC-64-AVRO as an int, MD5 and SHA-256.

  • Chapter 10

    Untrusted input and limits

    AvroLimits, the checks that are always on, compression bombs and deep values.

  • Chapter 11

    Errors

    The sealed AvroException, an exhaustive switch, and what each type carries.

  • Chapter 12

    Code generation

    Dart classes, enums and sealed unions from .avsc files, TypedCodec, and the generator as a library.

  • Chapter 13

    Sort order

    compare, compareBytes without decoding, and TypedCodec.compare, by Avro's sort order.

  • Chapter 14

    Schema compatibility

    checkCompatibility: every reason a reader schema cannot read a writer's data, before any data is read.

  • Chapter 15

    Flutter web

    dart2wasm, what dart2js throws, and deflate without dart:io.
