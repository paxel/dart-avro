Avro data declares lengths and counts before their content, and a compressed block can expand a thousandfold. Bytes from an untrusted sender can use both to make a reader allocate far more than it was sent. The package bounds that by default.

The limits

One AvroLimits object holds every limit. Its defaults are generous but finite, so a small input cannot expand without bound:

Field Default Bounds Checked by
maxSchemaBytes 1 MiB The JSON text of one schema, in UTF-8 bytes Schema.parse
maxSchemaDepth 64 The nesting of arrays and objects in a schema's JSON textSchema.parse
maxValueDepth 1024 The nesting depth of one value, and of its JSON text AvroCodec
maxZeroSizeItems1,048,576 The items of one array whose items take zero bytes AvroCodec
maxBlockBytes 64 MiB One block of a container file, decompressed; in the stream reader also compressed, and the headerAvroFileReader, AvroFileStreamReader
maxTotalBytes 1 GiB All blocks of a container file together, decompressed AvroFileReader, AvroFileStreamReader

Schema.parse, AvroCodec, AvroFileReader and AvroFileStreamReader.open each take a limits: argument, and each checks the fields in its row. The reader also uses its limits to parse the file's schema, and for the codec of records() without an argument. A codec you pass to records(codec) keeps its own limits for the values. Input over a limit throws LimitExceededException, whose limit is the name of the field.

A field set to null means no limit for that field. AvroLimits.none sets them all to null; use it for input you trust, such as files your own program wrote. 

import 'package:avro/avro.dart';

// The limits of one application, declared once: stricter for blocks, the rest as default.
const appLimits = AvroLimits(
  maxBlockBytes: 16 * 1024 * 1024,
  maxTotalBytes: 256 * 1024 * 1024,
);

void main() {
  final schema = Schema.parse('"string"', limits: appLimits);
  final codec = AvroCodec(writer: schema, limits: appLimits);
  final file = (AvroFileWriter(codec)..add('hello')).close();

  print(AvroFileReader(file, limits: appLimits).records().toList());
  print(AvroFileReader(file, limits: AvroLimits.none).records().toList());
  print('${appLimits.maxValueDepth} ${AvroLimits.none.maxValueDepth}');
}

Always on

Some checks need no limit and cannot be turned off:

  • A declared length or count is checked against the bytes that are left before anything is allocated. A string that claims a terabyte in a ten-byte input throws at once.
  • The item count of an array or map is checked against the smallest size its items can have: 1,000 long values need at least 1,000 bytes.
  • Negative lengths are rejected, and so are varints longer than 64 bits and int values beyond 32 bits.
  • Strings must be well-formed UTF-8, with no encoded surrogate code points.
  • A container file's block must end with the file's sync marker, and hold exactly the records it declares.

Each of these throws DecodeException, with the offset where the problem starts.

import 'dart:typed_data';

import 'package:avro/avro.dart';

void main() {
  final long = AvroCodec(writer: Schema.parse('"long"'));
  Uint8List declare(int n) => long.encode(n); // a length or count is a long

  final cases = [
    ('"string"', [...declare(1 << 40), 0x61]),
    ('{"type": "array", "items": "long"}', [...declare(1000), 2, 4, 6]),
    ('"bytes"', [...declare(-1)]),
    ('"string"', [...declare(2), 0xc0, 0x80]), // an overlong UTF-8 encoding
  ];
  for (final (schema, bytes) in cases) {
    try {
      AvroCodec(writer: Schema.parse(schema)).decode(Uint8List.fromList(bytes));
    } on DecodeException catch (e) {
      print(e);
    }
  }
}

Compression bombs

A compressed block can be tiny and decompress to gigabytes. Whatever the compression, the reader stops decompressing a block as soon as the output passes maxBlockBytes, or, counted over the whole file, maxTotalBytes. A bomb is never decompressed in full. A snappy block declares its length first, so it fails on that before anything is decompressed. 

import 'dart:typed_data';

import 'package:avro/avro.dart';

void main() {
  final codec = AvroCodec(writer: Schema.parse('"bytes"'));
  const strict = AvroLimits(maxBlockBytes: 1024 * 1024);
  for (final compression in ['deflate', 'snappy', 'bzip2', 'xz', 'zstandard']) {
    // 5 MiB of zeros in one block.
    final writer = AvroFileWriter(codec, compression: compression);
    writer.add(Uint8List(5 * 1024 * 1024));
    final file = writer.close();
    try {
      AvroFileReader(file, limits: strict).records().toList();
    } on LimitExceededException catch (e) {
      print('$compression: ${e.limit}: ${e.message}');
    }
    if (compression == 'deflate') {
      print(AvroFileReader(file).records().length); // within the default 64 MiB
    }
  }
}

Streamed files

AvroFileStreamReader buffers a block's compressed bytes before it decompresses them, and the header before it returns from open. maxBlockBytes bounds both: a block that declares more compressed bytes fails before they are read, and a header that needs more bytes fails in open. AvroFileReader has the whole file in memory already, so it checks neither. 

import 'dart:typed_data';

import 'package:avro/avro.dart';

Future<void> main() async {
  final codec = AvroCodec(writer: Schema.parse('"bytes"'));
  const strict = AvroLimits(maxBlockBytes: 1024 * 1024);

  // A block of 2 MiB: refused before its bytes are buffered.
  final big = (AvroFileWriter(codec)..add(Uint8List(2 * 1024 * 1024))).close();
  final reader = await AvroFileStreamReader.open(Stream.value(big), limits: strict);
  try {
    await reader.records().toList();
  } on LimitExceededException catch (e) {
    print('${e.limit}: ${e.message}');
  }

  // A header of more than 1 MiB: refused by open.
  final header = AvroFileWriter(codec, metadata: {'app.blob': Uint8List(2 * 1024 * 1024)}).close();
  try {
    await AvroFileStreamReader.open(Stream.value(header), limits: strict);
  } on LimitExceededException catch (e) {
    print('${e.limit}: ${e.message}');
  }
  print(AvroFileReader(header, limits: strict).header.metadata.length);
}

Deep values: maxValueDepth

A recursive schema, such as a linked list, lets a value nest as deep as the sender likes, and a deep value would exhaust the stack of a recursive decoder. maxValueDepth bounds the depth. The value itself is at depth 0; each record field, array item, map value and union branch goes one level deeper. In the list below, each node takes two levels: its field next and the branch of the union. 

import 'package:avro/avro.dart';

void main() {
  final schema = Schema.parse('''
  {"type": "record", "name": "Node", "fields": [
    {"name": "next", "type": ["null", "Node"]}
  ]}
  ''');
  Object? list(int length) {
    Object? node;
    for (var i = 0; i < length; i++) {
      node = {'next': node};
    }
    return node;
  }

  final bytes = AvroCodec(writer: schema).encode(list(6));

  final shallow = AvroCodec(writer: schema, limits: const AvroLimits(maxValueDepth: 10));
  print(shallow.decode(AvroCodec(writer: schema).encode(list(5))));
  try {
    shallow.decode(bytes);
  } on LimitExceededException catch (e) {
    print('${e.limit}: ${e.message}');
  }
  try {
    shallow.encode(list(6));
  } on LimitExceededException catch (e) {
    print('${e.limit}: ${e.message}');
  }
}

encode checks the same depth, so a codec does not write what it would refuse to read; there too, the failure is a LimitExceededException. decodeJson also checks the nesting of the JSON text before it parses it: JSON nested deeper than maxValueDepth throws LimitExceededException without being parsed.

Empty items: maxZeroSizeItems

Most items take at least one byte, so their count is bounded by the input. An item of null, of a fixed of size 0, or of a record of such fields takes no bytes at all: four bytes can declare a million of them, and decoding would build a list of a million entries. maxZeroSizeItems bounds the count of one array of such items. Map entries always take a byte for the key, so maps need no such limit. 

import 'dart:typed_data';

import 'package:avro/avro.dart';

void main() {
  final nulls = AvroCodec(writer: Schema.parse('{"type": "array", "items": "null"}'));
  final count = AvroCodec(writer: Schema.parse('"long"')).encode(2000000);
  final bytes = Uint8List.fromList([...count, 0]); // 2,000,000 nulls, then the end
  print(bytes.length);

  try {
    nulls.decode(bytes);
  } on LimitExceededException catch (e) {
    print('${e.limit}: ${e.message}');
  }

  final trusting = AvroCodec(writer: nulls.writer, limits: AvroLimits.none);
  print((trusting.decode(bytes) as List).length);
}

The reader applies its own maxZeroSizeItems to the record count of a block whose records take zero bytes; a block over it throws LimitExceededException.

A checklist for untrusted bytes

  • Declare one AvroLimits constant for your application and pass it everywhere: to Schema.parse, to every AvroCodec, to every AvroFileReader and to every AvroFileStreamReader.open.
  • Read a file's header first, and decode with a codec of a schema you know; see Container files.
  • Choose a single-object codec by fingerprint from the codecs you made, never from a schema the sender supplied; see Single-object encoding.
  • Catch AvroException at the boundary where the bytes come in; see Errors.
