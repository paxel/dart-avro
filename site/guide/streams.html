AvroFileReader and AvroFileWriter hold the whole file in memory. AvroFileStreamReader reads a container file from a Stream<List<int>>, and AvroFileStreamWriter writes one to a StreamSink<List<int>>, such as a file of dart:io or a socket, with one block in memory at a time.

Write and read a file

AvroFileStreamWriter(codec, sink, …) takes the options of AvroFileWriter: compression, metadata, schemaJson, syncMarker and blockSize, with the same defaults and checks. It writes the header to the sink at once, and each block when it reaches blockSize or at flush(). close() writes the last block, closes the sink, and completes when the sink is closed.

AvroFileStreamReader.open(stream, limits:) completes once the header has arrived, so header is there before any block is read. records() is a Stream of the records, decoded as each block arrives. 

import 'dart:io';

import 'package:avro/avro.dart';

Future<void> main() async {
  final codec = AvroCodec(writer: Schema.parse('''
  {"type": "record", "name": "Event", "fields": [
    {"name": "id", "type": "long"}, {"name": "kind", "type": "string"}
  ]}
  '''));
  final dir = Directory.systemTemp.createTempSync('avro');
  final file = File('${dir.path}/events.avro');

  // Write: the header at once, each block as it ends.
  final writer = AvroFileStreamWriter(codec, file.openWrite(), compression: 'zstandard');
  for (var id = 1; id <= 3; id++) {
    writer.add({'id': id, 'kind': id.isOdd ? 'odd' : 'even'});
  }
  await writer.close(); // the last block, then the file is closed

  // Read: open completes once the header has arrived.
  final reader = await AvroFileStreamReader.open(file.openRead());
  print(reader.header.compression);
  await for (final record in reader.records()) {
    print(record);
  }

  dir.deleteSync(recursive: true);
}

The same bytes and the same rules

The stream writer writes byte for byte what AvroFileWriter returns for the same records, flushes and sync marker, and the stream reader returns the records, the errors and the offsets that AvroFileReader gives for the same bytes, however the stream cuts them into chunks. What the Container files guide says holds for both:

  • add throws EncodeException for a record that does not fit, and leaves the block as it was.
  • A metadata key starting with avro., a syncMarker that is not 16 bytes or a schemaJson of another schema throw ArgumentError, and an unknown compression throws UnsupportedCompressionException, before anything is written to the sink.
  • records(codec) decodes with your codec, whose writer schema must have the canonical form of the file's schema; otherwise the stream has a DecodeException before the first record.
  • The stream of records ends with a DecodeException for a malformed or cut-off block, and with a LimitExceededException for a block over the limits, after the records before it.
import 'dart:async';
import 'dart:typed_data';

import 'package:avro/avro.dart';

Future<void> main() async {
  final codec = AvroCodec(writer: Schema.parse('"string"'));
  final sync = Uint8List.fromList(List.generate(16, (i) => i));

  // The stream writer writes the bytes AvroFileWriter returns.
  final sink = StreamController<List<int>>();
  final collected = sink.stream.expand((chunk) => chunk).toList();
  final writer = AvroFileStreamWriter(codec, sink, syncMarker: sync, compression: 'snappy')
    ..add('a')
    ..add('b')
    ..flush() // one block: a, b
    ..add('c');
  await writer.close(); // one more block: c
  final streamed = Uint8List.fromList(await collected);

  final memory = AvroFileWriter(codec, syncMarker: sync, compression: 'snappy')
    ..add('a')
    ..add('b')
    ..flush()
    ..add('c');
  print(_same(streamed, memory.close()));

  // The reader takes the bytes in chunks of any size, here 7 bytes each.
  Stream<List<int>> chunks() async* {
    for (var i = 0; i < streamed.length; i += 7) {
      yield streamed.sublist(i, i + 7 > streamed.length ? streamed.length : i + 7);
    }
  }

  final reader = await AvroFileStreamReader.open(chunks());
  print(await reader.records().toList());

  // Stop early: cancel ends the records without an error.
  final again = await AvroFileStreamReader.open(chunks());
  await for (final record in again.records()) {
    print(record);
    await again.cancel();
  }
  try {
    again.records();
  } on StateError catch (e) {
    print(e.message);
  }
}

bool _same(Uint8List a, Uint8List b) =>
    a.length == b.length && Iterable.generate(a.length).every((i) => a[i] == b[i]);

Stopping and errors of the stream

  • records() can be called once. A second call, or a call after cancel(), throws StateError.
  • cancel() cancels the subscription to the input. A stream of records that is running ends, without an error.
  • The subscription to the input is cancelled when open fails and when the stream of records ends.
  • An error of the input stream itself, such as a FileSystemException, is passed on as it is, not wrapped.
  • The writer's add, flush and close throw StateError after close. An error of the sink is not wrapped either.

Memory

The reader holds the header while it reads it, and then one block at a time: its compressed bytes and the decompressed records. maxBlockBytes bounds both. A block that declares more compressed bytes than maxBlockBytes fails before its bytes are buffered, and so does a header longer than maxBlockBytes, in open; see the limits guide.

The writer holds the current block until it ends, and hands each block to the sink with add; it does not wait for the sink. A sink that buffers, such as the IOSink of File.openWrite, keeps what it has not written yet: when you write many blocks to a slow sink, await the sink's own flush() now and then, before you add more records.
