avro is a pure-Dart implementation of Apache Avro 1.12: schemas, binary, single-object and JSON encoding, schema resolution, fingerprints and object container files.

What it is

The package reads an Avro schema from its JSON text and gives you a codec for it. The codec turns Dart values into Avro's binary encoding and back. Records and maps are Map<String, Object?>, arrays are List<Object?>; or, with dart run avro:generate, immutable Dart classes generated from your schemas. A second schema lets the codec read old data as a newer shape, by Avro's schema resolution. The same values have a JSON encoding. Container files, the .avro files other Avro libraries write, are read and written in memory or as streams, in every compression of the specification.

It has two public libraries: package:avro/avro.dart, and package:avro/generate.dart, the code generator for build steps. It has two direct dependencies: crypto, for the MD5 and SHA-256 fingerprints, and archive, for the compressions bzip2, xz and zstandard.

Native only

The package runs on the Dart VM and AOT: Android, iOS, Linux, macOS and Windows. Flutter web is not supported. The package relies on 64-bit int values for Avro's long and on dart:io for DEFLATE.

What 0.3.0 covers

  • Every primitive, complex and logical type of Avro 1.12.
  • Binary encoding, single-object encoding and JSON encoding.
  • Schema parsing, and schema resolution between a writer and a reader schema.
  • Parsing Canonical Form, with the fingerprints CRC-64-AVRO, MD5 and SHA-256.
  • Object container files, read and write, in memory or as streams, compressed with null, deflate, snappy, bzip2, xz or zstandard.
  • Limits on untrusted input, on by default.
  • Code generation of immutable Dart classes, enums and sealed unions from .avsc files, with TypedCodec, as a command and as a library.

What 0.3.0 does not cover

  • The Avro IPC/RPC protocol.

Install

Add the package to the dependencies of your pubspec.yaml:

dependencies:
  avro: ^0.3.0

Then follow Getting started: a schema, a record, and a container file in five minutes.
