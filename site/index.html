avro is a pure-Dart implementation of the binary core of Apache Avro 1.12: schemas, binary and single-object encoding, schema resolution, fingerprints and object container files.

What it is

The package reads an Avro schema from its JSON text and gives you a codec for it. The codec turns Dart values into Avro's binary encoding and back. Records and maps are Map<String, Object?>, arrays are List<Object?>; there is no code generation. A second schema lets the codec read old data as a newer shape, by Avro's schema resolution. Container files, the .avro files other Avro libraries write, are read and written in memory.

It has one public library, package:avro/avro.dart, and one dependency, crypto, for the MD5 and SHA-256 fingerprints.

Native only

The package runs on the Dart VM and AOT: Android, iOS, Linux, macOS and Windows. Flutter web is not supported. The package relies on 64-bit int values for Avro's long and on dart:io for DEFLATE.

What 0.1.0 covers

  • Every primitive, complex and logical type of Avro 1.12.
  • Binary encoding and single-object encoding.
  • Schema parsing, and schema resolution between a writer and a reader schema.
  • Parsing Canonical Form, with the fingerprints CRC-64-AVRO, MD5 and SHA-256.
  • Object container files, read and write, compressed with null or deflate.
  • Limits on untrusted input, on by default.

What 0.1.0 does not cover

  • JSON encoding.
  • The compressions snappy, bzip2, xz and zstandard. A file that uses one of them is rejected.
  • The Avro IPC/RPC protocol.
  • Code generation of typed Dart classes.

Install

Add the package to the dependencies of your pubspec.yaml:

dependencies:
  avro: ^0.1.0

Then follow Getting started: a schema, a record, and a container file in five minutes.
