The compressions of container files, and the classes that read and write them. The guides Container files, Compressions and Streamed container files show them at work.

The compressions

avro.codecReadWriteImplemented by Notes
null yes yes this package The default; also a file without avro.codec
deflate yes yes dart:io Raw DEFLATE
snappy yes yes this package Each block followed by the big-endian CRC32 of its uncompressed data, checked on reading; the declared length is checked before anything is allocated
bzip2 yes yes archive Checksums verified on reading
xz yes yes archive Written stored: valid xz, but not compressed. Checksums verified on reading
zstandard yes yes archive Written with the frame's checksum. Checksums verified on reading
anything else no no UnsupportedCompressionException from the constructor of a writer, from AvroFileReader and from AvroFileStreamReader.open

For every compression, the readers stop decompressing a block as soon as it exceeds maxBlockBytes, or the file maxTotalBytes, and throw LimitExceededException. A memory cap of an archive decoder, such as a zstandard window over 128 MiB, throws DecodeException.

The four types

Type Input or output In memory
AvroFileWriter Returns the file from close() as a Uint8ListThe whole file
AvroFileReader A Uint8List of the whole file The whole file, and one decompressed block
AvroFileStreamWriterA StreamSink<List<int>>The current block
AvroFileStreamReaderA Stream<List<int>>The header while it is read, then one block, compressed and decompressed

The two writers write the same bytes for the same records, flushes and sync marker. The two readers return the same records, errors and offsets for the same bytes, except for the limits that only the stream reader checks.

The writers

AvroFileWriter(codec, {…}) and AvroFileStreamWriter(codec, sink, {…}) take the same named arguments:

Argument Default Rules
compression'null' One of the six above, or UnsupportedCompressionException

schemaJson the writer schema's text Written exactly as given; another canonical form than the writer schema's throws ArgumentError

blockSize 65,536 bytes A block ends after the record that makes it reach this size, before compression
Member AvroFileWriter AvroFileStreamWriter
constructor Checks the arguments Checks the arguments, then writes the header to the sink; nothing is written if a check fails
add(record)Encodes one record into the block The same, and writes the block to the sink when it reaches blockSize

codec, compression, syncMarker, blockSizeThe values the writer was made with

add throws EncodeException for a record that does not fit, and leaves the block unchanged. After close, add, flush and close throw StateError. The stream writer does not wait for the sink, and an error of the sink is not wrapped.
