The Dart value of every Avro type and logical type, for encode and for decode. A value that does not fit throws EncodeException; bytes that do not decode throw DecodeException. The Values and unions guide shows them at work.

AvroCodec(decodeBranches: true) applies it in decode, decodeSingleObject, decodeJson, the records of a container file read with the codec, and the reader defaults that resolution fills in, nested unions included. A value decoded with it encodes back to the same bytes. Branch.== compares the name, and the value with ==. TypedCodec always decodes with it.

A logical type the package does not know, or one on another underlying type than the table says, is ignored, and the value is that of the underlying type. So is a decimal with invalid parameters: no precision, a precision below 1, a scale below 0 or above the precision, or a precision that the fixed cannot hold.

The edges of each logical type

uuid

  • encode accepts a String in the form 8-4-4-4-12 of hexadecimal digits, in either case, and writes it in lower case on a string, or as its 16 bytes on a fixed.
  • decode returns lower case. On a string, a text that is not in that form throws DecodeException.

date

  • AvroDate(year, month, day) is a calendar date with no time zone, in the proleptic Gregorian calendar; epochDays and AvroDate.fromEpochDays convert to and from days since 1970-01-01. It prints as 2026-11-21.
  • A date beyond the days an int holds throws EncodeException.

time-millis, time-micros

  • A Duration since midnight. The package does not check that it is shorter than a day.
  • time-millis throws EncodeException for a Duration with microseconds, rather than lose them, and for one beyond the 32 bits of an int.

timestamp-millis, timestamp-micros

  • encode accepts any DateTime, in UTC or local time, and writes its instant. timestamp-millis throws EncodeException for a DateTime with microseconds, rather than lose them.
  • decode returns a DateTime in UTC.
  • A DateTime covers 100,000,000 days either side of 1970. A long beyond that, which is a valid encoding, throws DecodeException naming the field and the value, so that a field always has one Dart type.

timestamp-nanos

  • AvroTimestampNanos(epochNanoseconds), nanoseconds since 1970-01-01T00:00:00Z. Every long is a valid value.
  • toDateTime() returns the instant in UTC, truncated to the microsecond; AvroTimestampNanos.fromDateTime goes the other way.

local-timestamp-millis, -micros, -nanos

  • AvroLocalTimestamp(year, month, day, [hour, minute, second, nanosecond]) holds wall-clock fields with no time zone; it prints as 2026-11-21T09:30:00.000000000.
  • encode throws EncodeException where a finer fraction would be lost: a nanosecond that is not whole milliseconds for -millis, not whole microseconds for -micros.
  • epochMilliseconds, epochMicroseconds (null where a fraction would be lost) and epochNanoseconds give the time as if it were UTC; the factories fromEpochMilliseconds, fromEpochMicroseconds and fromEpochNanoseconds build one.
  • toDateTime() returns the wall-clock time in the device's local time zone, to the microsecond.
  • Two values are equal when they name the same wall-clock time, whatever fields they were built from.

decimal

  • AvroDecimal(unscaled, scale) is unscaled × 10-scale, with unscaled a BigInt. It prints as decimal text, such as 19.99.
  • encode throws EncodeException unless the scale is the schema's scale (0 when absent), and the unscaled value has at most precision digits and fits the fixed. Rescale the value yourself; the package does not round.
  • The bytes are the unscaled value in big-endian two's complement: as few as it needs on bytes, sign-extended to the size on fixed.
  • Equality compares unscaled and scale, so 1.0 and 1.00 are not equal.

big-decimal

  • The same AvroDecimal, with any scale, carried in the value.
  • The bytes value holds the unscaled value as Avro bytes (its length, then big-endian two's complement), followed by the scale as an Avro int. See Spec conformance for how this layout was chosen.

duration

  • AvroDuration(months, days, milliseconds), written as three unsigned 32-bit little-endian numbers in a fixed of 12.
  • A part below 0 or above 4,294,967,295 throws EncodeException.

Defaults

A field default is written in the schema as JSON and becomes the same Dart value as decode would return: a bytes or fixed default, a string of the characters U+0000 to U+00FF, becomes a Uint8List, and a default of a logical type becomes its Dart value. See Schemas and attributes.
