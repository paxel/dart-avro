The six subtypes of AvroException, what throws each, and what each carries. The Errors guide shows how to handle them.

The base class

sealed class AvroException implements Exception, with one field, message: what went wrong, in words. The subtypes are final, so the six below are all there are, and a switch over an AvroException that names them all is exhaustive.

SchemaParseException

The JSON text is not JSON, or not a valid Avro schema.

  • Thrown by Schema.parse, and so by AvroFileWriter for a schemaJson that is not a schema, and by AvroFileReader.records(), when the iteration starts, for a file whose avro.schema is not a schema.
  • path: where in the schema, such as Memo.fields[1].type, $ or $[2] from the root; null when the text is not JSON.

ResolutionException

A writer schema does not resolve against a reader schema.

  • Thrown by AvroCodec(writer:, reader:), before any data is read, for every problem that does not depend on the data.
  • Thrown by decode, decodeSingleObject and AvroFileReader.records(codec) for a datum that holds an enum symbol the reader lacks and has no default for, or a branch of a writer union that does not resolve.
  • path: from the constructor, a place in the schemas, such as Memo.written or Memo.tags[]; from decoding, the place in the value, such as $.colour.

DecodeException

The bytes are not a valid encoding.

  • Thrown by decode and decodeSingleObject: truncated or malformed data, a value beyond its type, bytes left over after the datum, a logical value that cannot be read.
  • Thrown by SingleObjectHeader.parse and decodeSingleObject: fewer than 10 bytes, no marker C3 01, and, for decodeSingleObject, a fingerprint that is not the writer schema's.
  • Thrown by the AvroFileReader constructor: no magic, a malformed header, no avro.schema, or avro.schema or avro.codec that is not UTF-8.
  • Thrown while iterating AvroFileReader.records: a malformed block, a sync marker that does not match, data that is not valid DEFLATE, a record count the block cannot hold, bytes left after the records.
  • offset: the byte where decoding failed, from the start of the bytes decoded; for the records of a container file, from the start of the decompressed block.
  • path: the place in the value when a logical type cannot be read, such as a timestamp-millis beyond DateTime or a uuid string that is not a UUID; otherwise null.

EncodeException

A value does not fit the schema it is encoded with.

  • Thrown by encode, encodeSingleObject and AvroFileWriter.add: a value of the wrong Dart type, a missing record field or an unknown key, an int beyond 32 bits, a wrong fixed size, an unknown enum symbol, an unpaired surrogate, a union value that fits no branch or more than one, a logical value that would lose precision or does not fit, a value nested deeper than maxValueDepth.
  • path: the place in the value: $, $.written.year, $.items[2].

LimitExceededException

Input exceeds one of the limits.

  • Thrown by Schema.parse for maxSchemaBytes and maxSchemaDepth, by decode and decodeSingleObject for maxValueDepth and maxZeroSizeItems, and while iterating AvroFileReader.records for maxBlockBytes and maxTotalBytes.
  • limit: the name of the AvroLimits field, such as maxBlockBytes.

UnsupportedCompressionException

A container file uses a compression this package does not support.

  • Thrown by the AvroFileReader constructor for a file whose avro.codec is not null or deflate, and by the AvroFileWriter constructor for such a compression.
  • compression: the value of avro.codec, or the argument.
