The six subtypes of AvroException, what throws each, and what each carries. The Errors guide shows how to handle them.

The base class

sealed class AvroException implements Exception, with one field, message: what went wrong, in words. The subtypes are final, so the six below are all there are, and a switch over an AvroException that names them all is exhaustive.

SchemaParseException

The JSON text is not JSON, or not a valid Avro schema.

  • Thrown by Schema.parse, and so by AvroFileWriter and AvroFileStreamWriter for a schemaJson that is not a schema, and by records of AvroFileReader and AvroFileStreamReader, when the records start, for a file whose avro.schema is not a schema.
  • path: where in the schema, such as Memo.fields[1].type, $ or $[2] from the root; null when the text is not JSON.

ResolutionException

A writer schema does not resolve against a reader schema.

  • Thrown by AvroCodec(writer:, reader:), before any data is read, for every problem that does not depend on the data.
  • Thrown by decode, decodeSingleObject, decodeJson and the records(codec) of both readers for a datum that holds an enum symbol the reader lacks and has no default for, or a branch of a writer union that does not resolve.
  • path: from the constructor, a place in the schemas, such as Memo.written or Memo.tags[]; from decoding, the place in the value, such as $.colour.

DecodeException

The bytes are not a valid encoding.

  • Thrown by decode and decodeSingleObject: truncated or malformed data, a value beyond its type, bytes left over after the datum, a logical value that cannot be read.
  • Thrown by decodeJson: text that is not JSON, or JSON that is not a value of the writer schema: a missing or unknown record field, a value of the wrong JSON type, an int beyond 32 bits, a union key that names no branch or two, a code point over 255 in bytes or fixed.
  • Thrown by SingleObjectHeader.parse and decodeSingleObject: fewer than 10 bytes, no marker C3 01, and, for decodeSingleObject, a fingerprint that is not the writer schema's.
  • Thrown by the AvroFileReader constructor and AvroFileStreamReader.open: no magic, a malformed or cut-off header, no avro.schema, or avro.schema or avro.codec that is not UTF-8.
  • Thrown while reading the records of either reader: a malformed or cut-off block, a sync marker that does not match, data that is not valid for its compression, a snappy CRC32 or another checksum that does not match, a block over a memory cap of the archive decoders, a record count the block cannot hold, bytes left after the records; and, before the first record, a codec whose writer schema is not the file's.
  • offset: the byte where decoding failed, from the start of the bytes decoded; for the records of a container file, from the start of the decompressed block; 0 for decodeJson.
  • blockOffset: for the records of a container file, the file offset at which the record's block starts; toString then reads DecodeException at byte 1 of the block at byte 79: …. Null outside container files.
  • path: the place in the value when a logical type cannot be read, such as a timestamp-millis beyond DateTime or a uuid string that is not a UUID, and the place in the JSON when decodeJson fails on a value, such as $.payload; otherwise null.

EncodeException

A value does not fit the schema it is encoded with.

  • Thrown by encode, encodeSingleObject, encodeJson and the add of both writers: a value of the wrong Dart type, a missing record field or an unknown key, an int beyond 32 bits, a wrong fixed size, an unknown enum symbol, an unpaired surrogate, a union value that fits no branch or more than one, a logical value that would lose precision or does not fit.
  • path: the place in the value: $, $.written.year, $.items[2].

LimitExceededException

Input exceeds one of the limits.

  • Thrown by Schema.parse for maxSchemaBytes and maxSchemaDepth, by decode, decodeSingleObject, decodeJson, encode, encodeSingleObject and encodeJson for maxValueDepth, by decode, decodeSingleObject and decodeJson for maxZeroSizeItems, while reading the records of either reader for maxBlockBytes, maxTotalBytes and maxZeroSizeItems, and by AvroFileStreamReader.open for maxBlockBytes, for the header. Every limit throws this exception, whatever the direction.
  • limit: the name of the AvroLimits field, such as maxBlockBytes.

UnsupportedCompressionException

A container file uses a compression this package does not support.

  • Thrown by the AvroFileReader constructor and AvroFileStreamReader.open for a file whose avro.codec is none of null, deflate, snappy, bzip2, xz and zstandard, and by the AvroFileWriter and AvroFileStreamWriter constructors for such a compression.
  • compression: the value of avro.codec, or the argument.
