What of the Avro 1.12 specification version 0.3.0 implements, and how that is checked.

In 0.3.0

Part of the specification Status
Schema declaration: primitive, complex and named types, aliases, defaults Complete
Logical types All of 1.12: decimal, big-decimal, uuid, date, time-millis, time-micros, timestamp-millis, timestamp-micros, timestamp-nanos, local-timestamp-millis, -micros, -nanos, duration
Binary encoding Complete; array and map blocks with a negative count and a byte size are read
JSON encoding Write and read: encodeJson and decodeJson, with schema resolution, union branches by full name, NaN and the infinities as strings
Single-object encoding Complete
Schema resolution Complete
Parsing Canonical Form Complete
Fingerprints CRC-64-AVRO, MD5, SHA-256
Object container files Read and write, in memory and as streams, with every compression of the specification: null, deflate, snappy, bzip2, xz (written stored) and zstandard

Not in 0.3.0

Part of the specification What happens instead
The IPC/RPC protocol and protocol declarations Not available; an error type is parsed and encoded as a record
Sort order A field's order is parsed and kept, but nothing compares by it

These may follow as minor versions. The package runs on the Dart VM and AOT, not on Flutter web.

An xz block is written as stored LZMA2 data, without compression, because the package archive writes xz only that way; the file is valid xz, and any reader of xz reads it.

Behaviour worth knowing

  • A union default is the value of the first branch it fits.
  • Named types match by their name without the namespace, or by the reader's aliases.
  • A logical type that the package does not know, or that is invalid, is read as its underlying type.
  • encode does not fill in defaults; every record field must be given.

The test oracles

dart test needs nothing but Dart. It checks the package against data that others wrote, so that it does not only agree with itself.

Oracle What it checks
Apache schema-tests.txt The canonical form and CRC-64-AVRO fingerprint of every schema in it
Apache interop.avsc Parsing and round trips of the Apache interop schema
Apache weather.avro, weather-deflate.avro, weather-snappy.avro, weather-zstd.avro, weather.jsonReading Apache's container files, compressed with null, deflate, snappy and zstandard, to the records of weather.json
Python-written weather-bzip2.avro, weather-zstandard.avro; weather-xz.avroThe same records, written by Python avro 1.12.2 with bzip2 and zstandard, and in a file built around an xz stream of Python's lzma, since Python avro has no xz
Compression bombs 200 MiB and 20 MiB of zeros compressed by Python and XZ Utils with bzip2, xz and zstandard, which must stop at the limits
Apache syncInMeta.avro A file whose metadata contains its own sync marker
AXT examples Canonical forms, a single-object message of 210 bytes and a container file of 5,020 bytes, written by fastavro 1.13.1
Hand-written cases Byte-exact encodings worked out from the specification, for every type and logical type

The Apache files are copied unchanged from the Apache Avro repository, tag release-1.12.2, under the Apache License 2.0; weather-deflate.avro and weather-zstd.avro, which that tag lacks, come from a later commit (AVRO-4172). The Python-written files and the bombs are made for this package, with the script next to them in test/data/compressions. The AXT examples come from AXT release v0.1.0, spec/envelope.md, section 10.

Interoperability with Python avro

A separate CI job round-trips data with the Python avro package 1.12.2, the official Apache library: Python writes and Dart reads, then Dart writes and Python reads. It covers four cases: the Apache interop schema, the logical types Python supports, a schema resolution with promotions, fields in another order, defaults and an enum default, and a union of primitives, two records and a map. Each case is compared as a container file with null, one with deflate, and as single datums: 12 comparisons in each direction, all passing. The other compressions are checked by the files above, not by the job.

Two gaps of Python avro 1.12.2 are left out of the job; the Dart tests cover both:

  • It writes a boolean in a union of boolean and double as a double.
  • It does not resolve an unknown enum symbol to the reader's default.

The job compares data, not fingerprints: Python avro 1.12.2 computes some canonical forms wrongly, such as {"type":"string"} for a primitive with a logical type. The fingerprints are pinned by schema-tests.txt.

What has no second implementation

Python avro does not support everything. These parts are checked by the hand-written cases from the specification only:

  • the JSON encoding, which Python avro does not have: the tests use JSON written by hand from the specification, and a one-off check with fastavro 1.13.1, not part of CI, matched, apart from fastavro's bare NaN tokens and its rejection of simple union names;
  • single-object encoding, which the AXT example message also checks, as written by fastavro;
  • timestamp-nanos;
  • local-timestamp-millis, -micros and -nanos;
  • big-decimal;
  • duration;
  • uuid on fixed.

Each but the JSON encoding is a thin layer over an encoding the interop job does check: long, bytes or fixed.

The big-decimal layout

A big-decimal carries its scale in each value. The package lays out the bytes of a value as the unscaled value first, as Avro bytes in big-endian two's complement, then the scale as an Avro int. This layout is believed to match the Java implementation, but it has not been checked against Java, and neither Python avro nor fastavro supports big-decimal.

Fuzzing

The entry points that take untrusted input, AvroCodec.decode (with single-object encoding), AvroCodec.decodeJson, AvroFileReader with its records and AvroFileStreamReader with its records, fed in chunks, are fuzzed by mutating valid inputs, files in every compression among them, at random. A run fails on any input that throws anything but an AvroException, or takes longer than two seconds. dart test runs 2,000 mutations with a fixed seed; a weekly CI job fuzzes for ten minutes.
