Five minutes, four steps: add the package, parse a schema, encode and decode a record, and write and read a container file. The examples build on each other; put them in one main() in that order.

Add the dependency

The package needs Dart 3.13 or later and runs on the Dart VM and AOT, not on Flutter web. Add it to the dependencies of your pubspec.yaml: 

dependencies:
  avro: ^0.1.0

Run dart pub get, or flutter pub get in a Flutter app, and import the one library:

import 'package:avro/avro.dart';

Parse a schema

A schema is JSON text. Schema.parse reads it into an immutable tree, and throws SchemaParseException if the text is not a valid Avro schema. 

final schema = Schema.parse('''
{
  "type": "record",
  "name": "User",
  "namespace": "com.example",
  "fields": [
    {"name": "name", "type": "string"},
    {"name": "age", "type": "int"},
    {"name": "email", "type": ["null", "string"], "default": null}
  ]
}
''');

Encode and decode a record

An AvroCodec encodes and decodes the values of one schema. A record is a Map<String, Object?> with one entry per field. Every field must be there, even one with a default. 

final codec = AvroCodec(writer: schema);

final bytes = codec.encode({'name': 'Ada', 'age': 36, 'email': null});
// bytes is a Uint8List: [6, 65, 100, 97, 72, 0]

final user = codec.decode(bytes) as Map<String, Object?>;
print(user['name']); // Ada

encode throws EncodeException if the value does not fit the schema. The exception names the place in the value: $.age if age is not an int. decode throws DecodeException if the bytes are not a valid encoding, or if bytes are left over after the value.

The email field is a union of null and string. The codec picks the branch from the value: null or a String. When more than one branch fits a value, you name the branch; Concepts shows how.

Write and read a container file

A container file holds many records of one schema, with the schema in its header. Other Avro libraries read and write the same files. AvroFileWriter writes one in memory; close returns its bytes. 

final writer = AvroFileWriter(codec, compression: 'deflate');
writer.add({'name': 'Ada', 'age': 36, 'email': 'ada@example.com'});
writer.add({'name': 'Alan', 'age': 41, 'email': null});
final Uint8List file = writer.close();

Uint8List comes from dart:typed_data. To store the file, write the bytes, for example with File('users.avro').writeAsBytesSync(file) from dart:io.

AvroFileReader reads the header at once. records() decodes the records lazily, one block at a time, with the schema stored in the file. 

final reader = AvroFileReader(file);
print(reader.header.compression); // deflate

for (final record in reader.records()) {
  print(record);
}
// {name: Ada, age: 36, email: ada@example.com}
// {name: Alan, age: 41, email: null}
